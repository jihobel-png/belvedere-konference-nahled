# Hotel Belvedere Praha — konference a eventy

[Otevřít prezentační náhled](https://jihobel-png.github.io/belvedere-konference-nahled/)

Samostatný veřejný návrh konferenční podstránky podle dodané identity Belvedere: IvyMode v nadpisech, Aventa pro text, originální logo, skutečné hotelové fotografie a video.

Formulář je ukázkový. Kontaktní údaje se nikam neodesílají ani neukládají. Tento projekt nemění hotelový web a neprovádí skutečné rezervace.

Média a značka náleží příslušným držitelům práv; zdrojový repozitář neposkytuje licenci k jejich dalšímu použití. Licencované webfonty se připravují pouze v publikačním buildu, nikoli jako volně redistribuovatelné zdrojové soubory. Produkční backend a soukromé podklady nejsou součástí tohoto repozitáře.
